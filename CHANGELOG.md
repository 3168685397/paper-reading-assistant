# Changelog / 变更记录

All notable changes to Science Reader are documented here.

Science Reader 的重要变更记录于此。

## 0.1.0

### English

- Added in-page text selection translation for Science pages.
- Added a draggable, viewport-constrained frosted-glass translation popover.
- Added Chinese translation, core meaning, and original English presentation.
- Added on-demand sentence structure, grammar, and academic vocabulary analysis.
- Added configurable OpenAI-compatible API support with Zod validation.
- Added local history for up to 50 deduplicated records and Markdown export.
- Added timeout, cancellation, retry, permission, privacy, and readable error handling.

### 简体中文

- 新增 Science 网页内划词翻译。
- 新增可拖动、限制在可视区域内的毛玻璃翻译悬浮卡片。
- 新增中文翻译、核心意思和英文原文展示。
- 新增按需句子主干、语法知识点和学术词汇分析。
- 新增可配置 OpenAI-compatible API 支持和 Zod 校验。
- 新增最多 50 条去重本地历史记录和 Markdown 导出。
- 新增超时、取消、重试、权限、隐私和易懂错误处理。
